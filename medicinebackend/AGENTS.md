# 后端开发规范

权威规则：`../docs/HIS开发文档.md` §1.3、§2.2、§4、§5。

- FastAPI + Pydantic 2 + sqlite3，路由与业务服务分开。
- SQL 参数化，启用外键、WAL、busy_timeout；写事务使用 BEGIN IMMEDIATE。
- 金额使用整数分，价格从服务端药品档案取得并保存处方快照。
- 收费预留，发药出库；所有副作用与审计同事务，重复操作不重复执行。
- 新结构通过版本化 SQL 迁移；不删库重建，不修改已执行迁移来掩盖结构问题。
- 权限与数据归属由后端检查；敏感信息不写日志。
- 测试使用临时数据库，运行 python -m pytest；不得以测试重置运行数据。
