# dudu 前端开发规范

权威文档：`../docs/HIS开发文档.md` §0.1、§2.1、§4。

- React + TypeScript strict + Vite。pages 管理页面，components 管理通用组件，api 集中封装请求及类型。
- 使用 TanStack Query 获取真实后端数据，修改后刷新有关缓存，退出后清空缓存。
- dudu 的视觉为冷白、墨蓝和钴蓝，采用顶部导航与横向页签，首页和登录页独立设计。
- 不沿用上一级项目的深绿宽侧栏、欢迎横幅与原布局。业务确认、校验和无障碍交互不能为美观省略。
- 可操作按钮必须有真实行为；表单提供加载、错误和成功反馈；列表有筛选、分页、空状态。
- 金额只用公共函数展示，权限既限制页面入口也由后端校验，禁止伪造统计数字。
- 关键流程使用真实 API 的浏览器测试。完成后执行 format:check、lint、build 和相关 E2E。
