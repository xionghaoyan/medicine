# dudu 医学系统开发约定

开始开发前必须阅读 `docs/HIS开发文档.md`。修改前端或后端时同时读取对应目录的 AGENTS.md。

- 所有产物保留在本目录，前端 `medicinefronted`，后端 `medicinebackend`。
- 使用 React + Vite + FastAPI + SQLite。业务规则、API 或字段变化，先同步开发文档再编码。
- dudu 使用自己的数据库、密钥、会话 cookie 和端口。不得修改上一级原项目及原始 PPT。
- 金额用整数分；挂号、库存预留、收款、发药、退费和审计在同一业务事务内。
- 只用虚构演示资料，后端强制检查角色和医生数据归属。
- 不清空业务库，不提交数据库、密钥、环境文件、虚拟环境或 node_modules。
- 测试仅使用隔离数据库；验收包含真实界面操作；只报告实际执行的结果。
